Tempel link video Instagram, dapatkan link tracking lokasi

LINK TRACKING ANDA:
⚠️ Perhatian: Link ini hanya akan dapat lokasi jika orang yang membuka mengizinkan akses lokasi di browsernya. Tidak ada cara bypass izin ini di browser modern.
Cara pakai:
1. Upload file HTML ini ke hosting (Netlify/Vercel/GitHub Pages).
2. Isi URL hosting di kolom "URL Website Anda".
3. Pilih endpoint penerima lokasi (Telegram paling praktis).
4. Klik Generate → copy link → kirim ke target.
5. Saat target buka, mereka akan diminta izin lokasi. Jika "Allow", koordinat masuk ke Anda, lalu otomatis redirect ke video Instagram.
